**Required fields:** Status, Priority (High/Medium/Low), Date Created, Origin, Author

**Fork-local line (DSM_0.2 §21.5).** This fork maintains an independent backlog from
`BACKLOG-001`, distinct from DSM Central's numbering. Bodies are name-free; developed
items are offered upstream (optional but recommended). Fork-local additions must never
contradict upstream TAB methodology (see BL-006). **Any session type** — main, STAA,
parallel — files here using the next fork-local number, not a guessed Central number
(see BL-005).
